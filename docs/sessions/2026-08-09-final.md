## Bilan de la journée

Pipeline complet construit de zéro en une journée :
- Phase 0 : socle, schéma MangaPage, interfaces, 40 tests
- Phase 1 : Magiv2 + manga-ocr, pipeline end-to-end
- Phase 2 : NarrativeScript, descriptions de scène, 40 tests
- Phase 3 : Kokoro TTS, premier audio, benchmark 28 pages
- Phase 4 : lecteur HTML accessible WCAG 2.2 AA

## État final

- 28/28 pages OK sur corpus manga moderne
- 637s d'audio total (22.8s/page)
- 40/40 tests passent
- Transcripts générés par page (benchmark_v4/transcripts/)
- Lecteur HTML fonctionnel avec navigation clavier complète

## Limites observées et documentées

1. SFX intégrés au dessin (hors bulles) non détectés par Magiv2
   — Magiv2 entraîné sur bulles structurées, pas texte flottant
   — Pages 1-1 et 3-1 : ザー、カァ、ヒュ manquants dans le transcript

2. Classification dialogue/sfx approximative
   — Tout est tagué [DIALOGUE] par défaut (placeholder Phase 1)
   — バタバタッ, ポッ devraient être [SFX]

3. OCR imprécis sur texte stylisé
   — バタバタッ reconnu comme バタいタッ
   — Fusion de textes adjacents sur certaines bboxes

## Décisions prises

- scene_description filtrées de l'audio (Qwen3-VL pas encore intégré)
- lang="ja" pour texte japonais, "fr" pour scene_description
- Filtre ponctuation pleine chasse dans Kokoro (silence 100ms)
